## 检查与构建

```bash
python3 Tools/generate_contract.py --check
node --test Tests/ReaderTests/*.test.cjs
swift test --filter 'CourseTests|GitHubTests|WorkflowTests'
python3 Tools/build.py macos
```

仅有 Command Line Tools 的 Mac 无法运行 XCTest 或构建 iOS；可构建 course 和 macOS App，并对真实目录、ZIP 做命令行校验。完整 Xcode 环境由 Clients 工作流提供。

受限环境将 CLANG_MODULE_CACHE_PATH 和 SWIFTPM_MODULECACHE_OVERRIDE 指向 .build 内，再使用 swift build --disable-sandbox --cache-path .build/cache。图标转换需要可用的系统图像服务。

静态导出命令为 course export <课程目录> <不存在的输出目录>。导出产物通过本地 HTTP 或受支持的静态托管阅读；不会自动发布网站。

## 人工验收

1. 用原 Apple ID 和 Bundle ID 覆盖安装 IPA，确认旧数学登录、离线内容、阅读历史与置顶。
2. 加入标准数学课程和机器学习课程，检查切换、目录、公式、代码、图片、练习答案及返回位置。
3. 加入无清单的公开 Markdown 仓库，检查子目录、排除路径和文件预览。
4. 给 GitHub App 增加另一个私有课程仓库权限，检查账号和下载。
5. 下载时切换课程或断网，确认不串用状态，失败后旧内容仍可读。
6. macOS 检查原生工具栏、⌘F 搜索、⌘[ 返回、⌘] 前进、⌘Y 历史、⌘O 课程切换；选择本地课程目录，编辑正文后刷新并检查作者工作流与实时日志。
7. Sideloadly 更新自动续签条目，确认使用新 IPA。

所有界面验收由用户本人完成；构建、单元测试及静态产物校验不代替真机验收。
