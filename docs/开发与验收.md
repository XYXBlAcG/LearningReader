## 检查与构建

```bash
python3 Tools/generate_contract.py --check
node --test Tests/ReaderTests/*.test.cjs
swift test --filter 'CourseTests|GitHubTests|WorkflowTests|HTMLImportTests|WebPageTests|CourseNavigationTests'
python3 Tools/build.py macos
```

Reader 测试先执行 `npm ci --ignore-scripts --no-audit --no-fund`，并运行 `node Tools/build_reader_vendor.mjs --check` 校验派生依赖。DOM 测试只在 Node 内加载本地渲染依赖，不操作浏览器。AI 定向检查执行 `swift test --filter 'AITests|AITransportTests|AISelectionTests|StudyRecordTests|StudyLibraryTests'`；只有 Command Line Tools 时使用完整 Xcode 的 Clients 工作流运行 XCTest；SwiftData 宏也需要该完整工具链。

仅有 Command Line Tools 的 Mac 无法运行 XCTest 或构建 iOS；可构建 course 和 macOS App，并对真实目录、ZIP 做命令行校验。完整 Xcode 环境由 Clients 工作流提供。macOS 只构建与发布 arm64；构建参数和架构校验以打包脚本为准。手动构建可从工作流声明的构建机选项中选择；产物架构由打包脚本单独限定与验证，课程命令行检查先编译当前主机可执行的工具。运行环境见 [GitHub 官方 runner 列表](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)。

受限环境将 CLANG_MODULE_CACHE_PATH 和 SWIFTPM_MODULECACHE_OVERRIDE 指向 .build 内，再使用 swift build --disable-sandbox --cache-path .build/cache。图标转换需要可用的系统图像服务。

静态导出命令为 course export <课程目录> <不存在的输出目录>。导出产物通过本地 HTTP 或受支持的静态托管阅读；不会自动发布网站。

## 人工验收

1. 用原 Apple ID 和 Bundle ID 覆盖安装 IPA，确认旧数学登录、离线内容、阅读历史与置顶。
2. 加入标准数学课程和机器学习课程，检查切换、目录、公式、代码、图片、练习答案及返回位置。
3. 加入无清单的公开 Markdown 仓库，检查子目录、排除路径和文件预览。
4. 给 GitHub App 增加另一个私有课程仓库权限，检查账号和下载。
5. 下载时切换课程或断网，确认不串用状态，失败后旧内容仍可读。
6. macOS 连续打开多篇笔记和练习，检查正文、返回、前进与重启恢复；检查原生工具栏、⌘F 搜索、⌘[ 返回、⌘] 前进、⌘Y 历史、⌘O 课程切换；选择本地课程目录，编辑正文后刷新并检查作者工作流与实时日志。
7. iOS 从“文件”导入单文件交互样例，检查脚本按钮、alert/confirm/prompt、网页存储、关闭后最近阅读与重启后再次打开。
8. 导入包含相对 JS、CSS、图片及多个 HTML 的文件夹，选择子目录入口，检查资源与网页前进后退；导入失败后旧最近项应保留。
9. 打开网址，检查 HTTP/HTTPS、无协议地址、网页内跳转、新窗口链接、前进后退手势和 JavaScript 对话框。网页默认全屏，只显示右上角按钮，菜单仅有“输入网址”和“退出”；重新输入相同网址可以重试加载，失败时按钮仍可用。
10. 导入失败时复制诊断，核对阶段、错误码和路径；在文件选择、导入、关闭页面后重试，检查旧最近项与课程状态。
11. Sideloadly 更新自动续签条目，确认使用新 IPA。
12. iOS 在设置添加实际使用的服务，分别测试文字与图片，切换默认服务，重启后检查配置与 Key 仍可用。填写错误地址、模型或 Key，确认错误可读、不会自动重复请求。
13. 在笔记、练习、本地 HTML 和普通网页选中文字，从长按菜单点“讲一讲”；选中公式检查内容不丢失。检查直觉、严谨过程、分数、矩阵、分段式、长公式横向滚动与复制后的 Markdown。
14. 实际拍照与选择图片，检查相机权限拒绝、旋转、裁剪、模糊题目、讲解与追问；生成时停止或关闭、换页和换课程，不得把旧回答混入新问题。全屏网页仍只显示右上角按钮。
15. 选择文件中间一句，在文件开头或结尾放置必须使用的条件，检查回答能结合全文；修改教学规范与公式规范并保存，开始新问题核对生效。检查中文标点旁的粗体、粗体中的公式、代码及转义星号，覆盖课程正文与 AI 回答。

16. DeepSeek 仅填写根地址，保存并选为默认后，在课程笔记和练习点击“讲一讲”；应立即进入准备、上下文选择或明确错误。系统菜单关闭导致选区折叠时仍应保留原选区，换文章后不得沿用旧选区。
17. 设置分别覆盖“询问开／关 × 默认全文开／关”，检查选择后正文条件是否按预期影响回答；选区模式检查请求不带全文。添加“出一道变式”，修改提示词、排序、停用、删除并重启检查保存；教学与公式规范仍生效。
18. 对支持推理的实际模型配置强度或预算，执行连接测试和正式讲解；关闭自定义后应沿用服务默认。不支持的参数应显示服务错误，不能静默回退。
19. 确认系统复制／全选菜单为中文；检查 iPhone 窄屏及 iPad 宽屏原生目录、搜索定位、置顶与当前页高亮，顶栏右栏按钮、目录锚点和图谱链接。
20. 历史搜索后向右滑动删除一条，清空并撤销；删除缺失文件记录；关闭再打开、重启和切换课程检查持久化，确认恢复当前阅读位置不补回已删记录。

21. 课程参考答案与 AI 讲解检查上下对照、独立滚动、题干收起、比例拖动、题图放大与公式；重复题号按科目匹配，起始题号非 1、多小问和标题式题目不能串题，返回原文保持位置且文件内容不变。
22. 默认自动保存有效回答，停止、断网、关闭和重启后检查保存内容及未完成状态；关闭自动保存后手动保存，继续追问与重新生成保留版本；存储失败应显示，改名不被流式更新覆盖，删除后迟到回调不得恢复记录。
23. 本地讲解搜索、课程筛选、右滑删除、批量删除、撤销、版本选择与删除；离线、移除课程或 Key 后仍可查看；返回原题、跨课程跳转、原文更新或删除时的反馈。
24. 导出 Markdown、包含题图的 ZIP 与全库 JSON；导入后检查题图、公式、上下文和版本，重复导入不重复建条目，坏备份不破坏原库。继续追问明确选择模型，核对沿用的上下文。

25. 目录同时展开多个层级，滚动离屏再返回、搜索再返回及切换文章，检查展开状态和当前文章定位；参考答案长标题、窄屏和大字号下检查图标完整。
26. 参考答案和 AI 讲解连续上下拖动分隔条，检查高度变化连续、无闪白、无重新加载，两个区域滚动位置保持；收起再展开题目，仍保留阅读位置。
27. 打印真实练习，覆盖仅题目、答案另页、三种留白、题图、矩阵、分段公式、长题跨页；检查预览、保存到“文件”、分享及系统打印，原文和阅读位置不变。

PDF 渲染检查运行于云端 iOS XCTest，使用 [生成器](../Tools/prepare_paper_fixture.cjs) 派生课程样例与分页样例，只调用排版和文件 API，不模拟屏幕操作；检查日志与 PDF 产物由 Clients 工作流保留。

所有界面验收由用户本人完成；构建、单元测试及静态产物校验不代替真机验收。
