# 学习记录与复习

仅 iOS 提供操作入口。课程与原始 Markdown 不保存个人收藏、错题或 AI 批注。

题目“对照”页支持收藏、加入错题集；更多菜单的“今日复习与错题集”查看本地题目。自测判错自动收录可在复习设置关闭。收藏和错题独立，只有开启“安排复习”的条目参与调度。术语卡片可加入知识点复习。

复习页显示到期数量，开始本轮时按每日建议量固定队列，并显示进度。“继续本轮”恢复当前位置和答案显示状态。点击“显示答案”后可同时回看题干与答案，再选择不会、模糊或掌握。“稍后处理”在本轮跳过该题，它仍留在到期列表；撤销评分恢复上次卡片状态与队列位置。算法、依赖版本和参数唯一入口为 [PracticeCore](../Sources/PracticeCore)、[Package.resolved](../Package.resolved)。

“作答记录（自评）”分别记录独立起手、提示、结论、证明、用时和卡点，随本题评分保存。未填写项保持未知，已有历史评分保留其原始数据。自评记录可支持之后的数学复盘，记忆评分由原有调度器处理。

题目更多菜单可“补充或修改参考答案”，将独立答案页的内容保存到本地题目。原课程文件保持原内容，便于在复习页对照和评分。

“设置 → 复习与提醒”支持目标保留率、每日建议量、提醒时间和通知预览。通知是提前安排的本地提醒；打开应用、完成复习或修改设置后重新安排。通知权限关闭不影响离线复习。学习摘要从该页面导出 Markdown，包含更新时间、题目、实际评分次数、下次复习和本地讲解索引，不包含 API Key。

已保存的课程 AI 讲解在原文可靠匹配的位置显示高亮，点击查看；重复或无法定位的文字不猜测位置，讲解仍保留在本地讲解库。“取消原文高亮”不删除回答，也可恢复；编辑讲解保存新版本，原回答可从版本选择中恢复。

人工验收：真机检查术语位置、长按选区、思考状态、右侧复制公式、收藏与错题、退出重开后的保存、评分撤销、通知点击、时区变化、讲解编辑恢复及课程同步后的高亮。界面操作由用户执行。

本地讲解的“选择”用于批量删除；“修改讲解内容”保存新版本。修改标题使用独立的大文本编辑页面，失败时保留输入。iOS 试卷导出默认省略页眉页脚及辅助章节，可分别开启页眉、页码或保留完整正文；不更改课程源文件。

课程笔记与练习的长按选区菜单提供“添加笔记”和“高亮”，使用本地原生编辑器与颜色选择器。个人标记不依赖 AI，保存后才出现在原文；可在“笔记与高亮”集中编辑、删除及撤销删除。不能可靠定位的记录保留，可修改关联选文重新关联。
