# 让模型创建可阅读的课程

## 直接使用的提示词

将下面文字连同本指南和所选模板交给模型。先填写方括号中的信息。

```text
请创建一套能被知序 LearningReader 直接读取的课程仓库。

学习者：[基础、已掌握内容、容易卡住的地方]
主题：[课程主题]
目标：[学完后应能完成的具体任务]
范围：[包含与不包含的主题]
深度：[入门、严格推导、实践或综合]
资料：[允许使用的教材、论文、公开课程或已有文件]

先阅读 LearningReader 的课程 Schema、最小模板和本指南。
先给课程大纲、先修关系与第一课样例，等我确认后逐课展开。
正文用 Markdown，公式使用 $...$ 和 $$...$$，代码使用带语言的围栏块。
每课先交代目标与先修，再从具体问题建立直觉，解释概念和方法，
提供完整例题或可复现实验，再给练习、自检与参考答案。
清楚解释符号、条件、方法适用范围和易错点。
知识链接指向真实存在的文件或标题，不虚构已完成课程或答案。
图片放在仓库内，用相对路径引用；外部资料标注来源和用途。
不要复制阅读器、App 源码或索引产物到课程仓库。
完成后运行 course validate，报告通过项目与仍需人工核验的内容。
```

## 建立仓库

复制 [最小模板](../Templates/minimal-course)，根据 [课程 Schema](../Schemas/course.schema.json) 填写 course.json。字段定义以 Schema 为准，不在这里维护第二份字段表。该清单仅描述内容边界和入口，文件树与正文标题生成阅读目录。

课程可以使用任何语言的目录名。常用结构是 README.md、lessons/、exercises/、assets/；文件使用 01、02 等数字前缀表达顺序。每篇文档一个一级标题。入口 README.md 用普通 Markdown 链接列出学习顺序，避免复制正文。最小模板不等于完整课程。

先修必须真实可达。没写完的章节可在大纲标注待完成，但不要放向不存在文件的链接。高级主题说明需要的基础，不用“显然”跳过关键推导。

## 正文与知识连接

普通链接用于导航：

```markdown
[配套练习](../exercises/01-introduction.md)
![图示](../assets/model.png)
```

知识连接使用 Obsidian 双链：

```markdown
- 前置：[[../lessons/01-introduction|基础概念]]
- 延伸：[[../lessons/02-generalization#验证集|泛化与验证]]
```

文件路径相对当前文章，或从课程根目录写完整路径；可以省略 .md。标题锚点按阅读器规范派生，使用指南中的验证命令检查实际目标。反向链接和图谱由 App 派生，不手工维护第二份列表。

笔记和练习可以在不同分组使用相同的分组内相对路径，供“对应笔记或练习”跳转。正文仍应明确链接到配套材料。

习题写完整条件、参数范围与要求，之后单独设“参考答案”。先解释解法切入点，再给推导和检查；数值题给可复现数据与结果。数学课程的额外要求由课程自己的规范提供。

## 课程术语

可在课程根目录增加 `术语/` 或 `glossary/`，逐词提供中文直觉、完整定义与例子。格式、别名、课程跳转及验收以 [术语作者入口](术语释义.md#课程作者) 和其 Schema 为准。术语内容只在词条 Markdown 维护，索引由知序派生；相关笔记必须真实存在。

## 机器学习课程

参考 [线性回归样例](../Templates/machine-learning-course)。说明模型假设、损失、训练与评价的区别，给出代码环境、输入数据、随机性和预期输出。防止把训练集表现当作泛化证明。

代码在读者自己的开发环境运行；App 展示代码，不执行 Notebook、安装依赖或训练模型。大型数据集、视频、Git LFS 和子模块不要当作必然离线可用的课程资源。

## 校验与交付

安装 macOS 知序后执行：

```bash
/Applications/知序.app/Contents/MacOS/course validate /绝对路径/课程仓库
```

开发环境执行：

```bash
swift run course validate Templates/machine-learning-course
```

校验实现入口是 [CourseIndexer](../Sources/LearningCore/CourseIndexer.swift)，渲染与知识链接入口是 [共享阅读引擎](../Sources/LearningCore/Resources/Reader)。源代码中的规则不在本指南复述。

提交前检查课程范围、先修闭环、推导与答案正确性、引用真实性和本地资源。程序校验不能证明教学结论正确。由学习者手动添加仓库，检查首课、公式、图片、练习与答案，断网后再次阅读。课程更新只提交课程，不重建 App。
