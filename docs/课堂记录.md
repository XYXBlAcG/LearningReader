# iOS 课堂记录

首页和页面菜单进入“课堂记录”，创建课堂后填写关键词，关联当前课程的章节，拍照或导入课件。关键词、标题和关联信息保存到本机；“生成整理草稿”仅发送勾选的资料。

照片、PDF 和 UTF-8 文本可参与整理。PDF 按选定页码提取文本并提供页面图片，需要配置支持图像的 AI 服务；每次每份最多 20 页。PPT 原文件可保存及系统预览，参与整理前先导出 PDF。单文件限制 50 MB。

草稿保留本次来源快照，以 `[S序号 p页码]` 对照下方资料清单并打开原件。AI 应区分资料、关键词与补充推导，缺失信息标为待核实；引用仍需人工核对。草稿可修改、预览公式并确认成个人笔记，不自动改写课程仓库。
