# 术语释义

## 阅读

课程正文中的虚线术语可点击查看直觉、定义、例子和相关笔记。同名有多个含义时先选择词条；数学公式使用课程相同的离线 Markdown 和 MathJax。长按选区仍可复制或使用“讲一讲”。卡片不会进入原文、AI 材料或试卷 PDF。

iOS 使用原生课程术语库与释义弹窗，提供搜索、学科筛选、相关笔记跳转和知识点复习。自动标注在“设置 → 阅读辅助”调整，按当前课程保存。macOS 阅读设置继续使用网页术语库与标注选项。iOS 课程题目和答案对照页沿用当前课程的词库与标注方式；AI 流式回答不逐字插入术语标记。

词库由当前课程提供，随课程同步后离线可用。不访问在线词典，也不为点击调用模型。没有术语目录的课程可正常阅读。

## 课程作者

在课程根目录使用 `术语/` 或 `glossary/`，二者任选其一。目录内支持学科子目录，每个词条一个 Markdown；README.md 为作者说明，不作为词条。术语文件不进入普通笔记目录。

词条由一个一级标题、紧接的 glossary JSON 围栏和正文组成；标题与元数据 term 一致。元数据以 [Schema](../Schemas/glossary.schema.json) 为唯一字段定义。

正文包含“## 直觉”“## 定义”“## 例子”，可继续添加条件、易混点及来源。数学使用课程的 `$...$`、`$$...$$`。例子应能独立读懂，定理必须写全适用条件。术语卡片读到的内容就是该 Markdown，不维护另一份释义。

ID 在课程内唯一且保持稳定。别名必须表达同一个概念；不同含义可以共用名称，但不能把子类型或相关定理冒充同义词。单字词可以在词库搜索，不在正文自动标注；登记更明确的短语别名可避免误匹配。

notes 指向当前课程已纳入阅读范围的路径和章节。导入时校验文件及锚点；标题匹配还可派生相关笔记，不把正文任意一次提及都认定为定义来源。related 指向同一词库存在的 ID。同步失败保留旧的课程版本。

执行 `course validate <课程目录>` 同时检查术语与课程关联；更新词条只需更新课程仓库并同步，不重建 App。

可使用 `course index <课程目录> > index.json`，再运行 `node Tools/check_glossary_render.cjs index.json` 检查全部词条的离线公式排版。
