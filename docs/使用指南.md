# 使用知序

讲义内的即时选择题见[随堂自测](随堂自测.md)：提交后查看反馈，可回到对应知识点，作答离线保存在本机。

## 添加与切换课程

macOS 打开工具栏的书架图标；iOS 打开原生课程目录或更多菜单中的“课程仓库”，选择“添加课程”，输入 GitHub 地址或 owner/repository，点击“预览课程”。检查标题与文件后，点击“加入课程并阅读”。分支留空使用仓库默认分支；课程只在仓库某个子目录时填写该目录。

没有 course.json 的现成仓库，勾选“按 Markdown 导入”；可填写需要排除的相对路径，每行一项。此配置只保存在本机，不修改上游仓库。Notebook 和 Python 文件不会在 App 内执行；外部视频与网页需要网络，Git LFS 和子模块内容不保证可离线获取。

公共课程可以匿名读取。私有课程需要先登录 GitHub，并将目标仓库加入 GitHub App 安装授权范围。课程列表支持切换已下载课程；移除课程会清除其本机副本，保留上游仓库原文。

macOS 也可选择本地课程文件夹。编辑文件后点击刷新，原文继续保存在所选文件夹中。课程清单可声明本地作者工作流；仅在本地来源显示，由你确认程序和参数后运行，日志在 App 中显示。远程快照不会执行作者工作流。

## iOS 本地 HTML

课程仓库列表下方的“本地 HTML”可从“文件”选择 .html 或 .htm，导入后直接阅读，并显示最近阅读文件。文件会复制到 App 内，重启后可再次打开；导入新文件替换最近项和旧副本，不修改原文件。长按最近项可移除副本。

网页带有独立 CSS、JavaScript 或图片时，选择“导入网页文件夹”，再选入口 HTML，保留原目录关系。原生 WebKit 启用 JavaScript、网页存储和对话框；当前文件再次打开时保留其网页存储。依赖服务器的接口仍需原服务，file URL 的模块加载和跨域行为遵循系统 WebKit 规则。此功能仅在 iOS 提供。

[单文件交互样例](../Examples/local-html/互动实验.html) 可用于人工检查按钮、网页存储和对话框。

## iOS 全屏浏览器

在课程仓库页面选择“打开网址”，输入 HTTP 或 HTTPS 地址；没有协议时默认使用 HTTPS。打开后网页全屏显示，右上角按钮仅提供“输入网址”和“退出”。在 App 内继续打开普通链接和新窗口链接，可用左右边缘滑动前进、后退。重新输入相同地址可再次加载；加载失败时仍可通过右上角更换地址或退出。

若 HTML 导入或打开失败，在错误提示中选择“复制诊断”，保留失败阶段、错误码及路径，便于定位。网页脚本与跨域行为遵循系统 WebKit 规则。

## GitHub 登录

iOS 从“设置 → GitHub 登录与设置”进入；macOS 打开“GitHub 设置”。填写自己的 GitHub App Client ID，点击登录，复制验证码并在打开的 GitHub 官方页面确认，随后返回知序。

创建 GitHub App 时启用 Device Flow，关闭 Webhook，Contents 设为 Read-only。将 App 安装到自己的账号，只选择需要读取的课程仓库。更换私有课程时，在设置内的“管理 GitHub App 仓库授权”添加目标仓库。无需 Client Secret 或私钥。

凭证保存在系统钥匙串。退出登录保留已下载课程。GitHub App 的注册和安装分别见 [GitHub 注册说明](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/registering-a-github-app) 与 [安装说明](https://docs.github.com/en/apps/using-github-apps/installing-a-github-app-from-a-third-party)。

## 阅读与更新

macOS 使用独立 AppKit 桌面窗口，工具栏直接提供目录、前进后退、历史、搜索、置顶和阅读设置；⌘F 搜索、⌘[ 返回、⌘] 前进、⌘Y 历史、⌘O 切换课程。“更多”可打开本地文件夹、GitHub 设置和日志面板。iOS 使用原生课程目录：宽屏显示左栏，窄屏从正文返回目录，选择章节后显示正文。目录支持文件夹、搜索和置顶；顶栏单个右栏按钮切换右侧工具，面板内选择“本页目录”或“知识关联”。历史页可一键清空、向右滑动删除单项；关闭历史页前可撤销上次删除或清空。删除不影响阅读位置，重启恢复也不会补回记录，主动重开文档会重新记入历史。左侧目录选章节。对应笔记与练习使用清单中两个分组的相同相对路径配对；其他配套材料通过正文链接进入。

课程返回前台会检查更新，也可手动刷新。下载失败保留当前快照。先在课程作者端提交并推送 GitHub，手机才能取得新内容；手机端只读。代码、公式和已下载图片支持离线阅读。

## 更新 App 与续签

使用相同 Apple ID 和原有 Bundle ID 覆盖安装新 IPA，不先卸载。图标与应用显示名变化不要求清除数据。

使用 Sideloadly 更新 IPA 时保持自动续签选项开启，让后台改为续签新产物。操作及限制以 [Sideloadly FAQ](https://sideloadly.io/faq) 为准。不要从源代码目录或可清理的临时目录长期运行续签工具。


## 打印练习

在 iOS 打开一套练习，从右上角菜单选择“导出试卷 PDF”。当前练习文件作为一套题，采用 A4 纵向排版，可选择作答留白及将答案另起页附后。生成后在预览页打印，或通过分享保存到“文件”。未识别到题号或明确答案分区时会提示核对；交互网页以文字提示保留，缺失图片需先修复后导出。课程原文不会改变。
