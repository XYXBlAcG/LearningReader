# 随堂自测

## 阅读与作答

讲义中的“随堂自测”支持单选、多选。选择后点“提交”，查看本次结果、各选项的解释和回看链接；也可“稍后再做”。多选题必须与正确选项集合完全一致，漏选和误选会分别提示。

“本节自测”列出当前文章的题目与状态，可直接跳转。首次结果保留，重新作答不会将首次错误覆盖成正确。先查看解析单独记录，后续作答不冒充独立通过；同组不同题首次独立答对后显示变式通过，不自动修改课程的 0—4 熟练度。

知序 iOS 与 macOS 离线判分，作答保存在设备本地。GitHub 同步题目，不同步个人作答。更改题目判分内容后，旧记录保留但不计入新题；解释文字修订不会重置记录。修改文件名而保留题目 ID，不会丢掉对应记录。

## 课程作者入口

- 题块格式以 [Schema](../Schemas/checkpoint.schema.json) 为唯一字段定义；在顶层段落之间插入语言标识为 checkpoint 的 JSON 围栏。
- ID 在课程内唯一、长期稳定。更改题干、选项或答案时递增 revision；选项按 ID 判分，不能用显示顺序指代答案。
- 反馈必须解释选项依据及误解，不能仅写“对/错”；review 指向课程内实际存在的 Markdown 文件或标题。
- 同一概念用 group 关联不同问法，不能复制同题充当变式。题干不要提前泄露答案。
- 普通作业的“题目—参考答案”格式保持原样，不把自测数据复制进普通题号区。
- 协议、题目 ID 与回看目标由 `course validate <课程目录>` 检查。具体命令见[开发与验收](开发与验收.md)。

MathJax 内容检查：`node Tools/check_checkpoint_content.cjs <本次修改的 Markdown 文件...>`。加 `--markdown` 可导出所有题干、选项与反馈的纯 Markdown，再交给课程自己的数学命令检查器；不能只检查围栏之外的正文。

新题块需要支持随堂自测的知序客户端；旧客户端会显示 JSON 代码。更新客户端后再同步带新题块的课程。

## 手动验收

1. 打开试点文章，选择但不提交，退出文章再返回，确认选择恢复且尚未露出解析。
2. 分别完成单选、多选；检查漏选、误选及每个选项的公式，确认提交前不显示正确项。
3. 先答错再重做答对，确认首次错误仍在；先查看解析后作答，确认状态不是首次独立答对。
4. 点回看链接、返回原处，断网退出并重新打开 App，确认位置、选择和反馈可恢复。
5. 检查 iPhone 竖屏、大字号、深色环境和 macOS 的选项点击区域、横向公式滚动及普通选区复制。
6. 更新题目答案及修订号、仅改解析、重命名文件，分别检查新旧记录边界；导出试卷时检查题干与可选答案附录，没有原始 JSON。

上述界面操作由学习者手动完成。自动检查使用纯逻辑、存储和静态文档渲染，不操控应用或浏览器。
