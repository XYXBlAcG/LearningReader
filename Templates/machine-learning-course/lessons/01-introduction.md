# 线性回归：从一个预测问题开始

## 目标与先修

先修：一次函数、平方与平均数。学完能解释模型、损失和拟合的区别。

## 问题与直觉

已有三个观测：输入 $x=0,1,2$，对应输出 $y=1,3,5$。用一条直线描述趋势，并预测 $x=3$ 的值。这里是教学样例，真实数据未必严格共线。

## 模型与推导

设 $\hat y=wx+b$。从 $x=0$ 的观测得到 $b=1$；从 $x=1$ 得到 $w=2$。三个点均符合，因此预测为 $7$。

平方损失衡量预测与观测的差距：

$$L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2.$$

样例在 $w=2,b=1$ 时损失为零，但训练误差小不保证新数据预测准确。模型提出函数形式，损失评价参数，拟合寻找参数。

## 代码与实验

以下代码只依赖 Python 标准库。复制到自己的 Python 环境运行；阅读器负责展示代码。

```python
x = [0, 1, 2]
y = [1, 3, 5]
w, b = 2, 1
loss = sum((w * xi + b - yi) ** 2 for xi, yi in zip(x, y)) / len(x)
print(loss, w * 3 + b)
```

预期输出：`0.0 7`。尝试令 $w=1$，记录损失如何变化。
