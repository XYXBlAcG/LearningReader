# 知序 · LearningReader

macOS 与 iOS 原生课程阅读器。添加 GitHub 课程仓库或 macOS 本地 Markdown 文件夹，下载后离线阅读，并按课程保留历史、位置和置顶。

- [使用与 GitHub 登录](docs/使用指南.md)
- [让模型创建课程](docs/模型创建课程指南.md)
- [开发、构建与验收](docs/开发与验收.md)
- [课程格式](Schemas/course.schema.json)
- [最小课程](Templates/minimal-course/README.md)
- [机器学习课程样例](Templates/machine-learning-course/README.md)

客户端发布产物来自 `Clients` 工作流：iOS 的 `LearningReader-unsigned.ipa` 需使用自己的 Apple ID 侧载；macOS 的知序 App 使用本机签名。课程仓库无需附带客户端源码、阅读器或内容构建工作流。
